# projetinho-d-epython-php-e-sql

# introdução 
este projeto serve para aprender a fazer um aplicação envolvendo minhas ares de conhecimento

# tecnologias

python: recebe os dados e os trnasforma em um json, e utiliza as bibliotecas: re(para validação do email) e json(para poder mexer com os arquivos json)
php: recebe o json criado, o verifica para ver se nao a divergencias com a base de dados e o adiciona no banco de dados
banco de dados: armazena os dados

# requisitos

python instaldo no pc
xampp instalado no pc
